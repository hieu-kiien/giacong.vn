# Commerce design tokens

Measured from the approved 1672 × 941 screenshots. Values are implementation targets and must be confirmed through screenshot comparison.

## Color

- Brand header: `#248f00` to `#35ad00` flat green range; use `#2f9e0b` as the primary token.
- Primary dark/hover: `#237a08`.
- Pale active surface: `#f1f8ec`.
- Pale B2B strip: `#f4faea`.
- Price: `#ef1726`.
- Body text: `#191919`.
- Secondary text: `#6f7177`.
- Border: `#dfe3df`.
- Warm product-image surfaces: cream/pink/blue/green, never generic gray placeholders.
- Focus ring: dark green plus white offset.

## Geometry

- Desktop header: 65 px.
- Content rail: max 1390 px on a 1672 px canvas; use a 1280–1390 px responsive rail.
- Main horizontal padding: 24 px desktop, 16 px tablet, 12 px mobile.
- Card radius: 10–12 px.
- Control radius: 7–9 px.
- Card border: 1 px.
- Product grid gap: 16–20 px.
- Minimum interactive target: 44 × 44 px.

## Typography

- Use the bundled SF Pro Display assets.
- Page title: 36–40 px desktop, 28–32 px mobile, 700 weight.
- Product title: 16–18 px, 650–700 weight.
- Price: 20–24 px, 700 weight.
- Body/control text: 14–16 px.
- Secondary metadata: 12–14 px.

## Effects

- Shadows are subtle: `0 2px 10px rgb(0 0 0 / 8%)`.
- Mega-menu overlay may use `0 18px 42px rgb(0 0 0 / 20%)`.
- No gradients, glassmorphism, oversized rounding or decorative motion.
