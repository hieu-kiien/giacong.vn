## 2. Logic Chain
1.  **URL Normalization & Cleaning**: Since sitemaps contain system/draft/checkout URLs (e.g. `/wp-admin/`, `/gio-hang/`, `/thanh-toan/`), and query parameters (like `?replytocom=...`) generate duplicate page crawls, the crawler must filter these out and strip all query parameters/anchors from URLs before pushing them to the queue.
2.  **Page Classification**:
    *   If the page is the root URL or has body class `home`, it is classified as `trang chủ`.
    *   If the page path ends with `/lien-he/` or has body class `page-id-14`, it is classified as `liên hệ`.
    *   If the body class has `single-product`, it is classified as `sản phẩm`.
    *   If the body class has `single-post` and the category is news (e.g. `category-tin-tuc`), it is classified as `tin tức`.
    *   If the body class has `single-post` and does not represent news, it is classified as `dịch vụ` (since 437 out of 451 posts correspond to services like packing, drying, and grinding).
    *   All index, policy, or miscellaneous pages are classified as `khác`.
3.  **Content Extraction**:
    *   Because `.entry-content` is present on both WooCommerce description tabs (`#tab-description`) and WordPress single posts, `.entry-content` is the unified primary selector for extracting main body content.
    *   Because images are lazy-loaded using the Flatsome theme builder, the parser must read `data-src` as the primary image URL, falling back to `src` only when `data-src` is missing or does not contain an SVG/placeholder.

## 3. Caveats
*   The News page (`/tin-tuc/`) currently lists no posts on the live site ("Nothing Found"). If a blog post is added in the future under the category "Tin tức", it will be classified as `tin tức` based on `body.category-tin-tuc`.
*   A small number of WordPress posts (14 out of 451) represent non-service content, such as draft posts (e.g. `/6972-2/`) or recipes (e.g. `/sot-cham-vit-quay-kinh-bac/`). These should be skipped if they do not match service patterns (e.g., if they return 0 length or are empty).
